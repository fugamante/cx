# XSHELF manuals (browse layout)

This folder is organized for fast browsing (source vs outputs vs build artifacts).
This repository documents the Rust-first runtime as the canonical technical direction.

## Read First

- Master manual PDF: `01_pdf/CX_MANUAL_MASTER.pdf`
- Web manual index: `02_web/index.html`
- Master manual HTML: `02_web/CX_MANUAL_MASTER.html`
- Master manual source: `03_src/latex/CX_MANUAL_MASTER.tex`

Manual source policy:
- Canonical source: `03_src/latex/CX_MANUAL_MASTER.tex`
- Generated PDF: `01_pdf/CX_MANUAL_MASTER.pdf`
- HTML mirror: `02_web/CX_MANUAL_MASTER.html`
- Public-surface ownership: `../project/PUBLIC_SURFACES.md`

Treat the LaTeX source as authoritative. Refresh the PDF from LaTeX when manual
content changes. The HTML file is a tracked convenience mirror unless an
automated HTML generation path is added.

## Outputs

- PDF: `01_pdf/` generated from the LaTeX source.
- HTML/CSS: `02_web/` tracked reader mirror; not currently generated by the
  documented rebuild command.
- Visual QA notes: `04_notes/WEB_VISUAL_QA.md`.

## Rebuild (master)

From repo root:

```bash
docs/manuals/build.sh
```

Equivalent PDF build:

```bash
/Library/TeX/texbin/latexmk -xelatex -interaction=nonstopmode -halt-on-error -file-line-error \
  -output-directory=docs/manuals/99_build/latexmk \
  docs/manuals/03_src/latex/CX_MANUAL_MASTER.tex
cp -f docs/manuals/99_build/latexmk/CX_MANUAL_MASTER.pdf docs/manuals/01_pdf/CX_MANUAL_MASTER.pdf
```

## Maintainer Scratch

- `99_build/` is ignored build output.
- `legacy/` is ignored local scratch/archive space. Promote useful source into
  the current structure before tracking it.

## Scope guard

- Rust (`cxrs`) is canonical runtime behavior for XSHELF.
- Bash is compatibility/bootstrap only.
- Manual updates should reflect Rust command/module behavior first, then fallback notes.

## Current documentation focus

- Centralized runtime configuration via `rust/cxrs/src/modules/config.rs` (`AppConfig` startup snapshot).
- Unified non-schema LLM command execution path via `rust/cxrs/src/modules/agentcmds.rs`:
  - `execute_llm_command(..., LlmMode)`
  - thin wrappers for `xshelf`/`cx` compatibility execution helpers (`cx`, `cxj`, `cxo`, `cxol`)
- Structured schema commands remain isolated in dedicated handlers (`structured_cmds`) to preserve strict schema contracts.
